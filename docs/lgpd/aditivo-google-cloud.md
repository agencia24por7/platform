# Aditivo de proteção de dados do Google Cloud (transferência internacional)

A política (`/privacidade`, seção 7) diz que a transferência para os EUA se apoia nas cláusulas contratuais dos
fornecedores. No Google Cloud isso é o **Cloud Data Processing Addendum (CDPA)**, complementado pelo **adendo
de LGPD** e pelas **cláusulas-padrão aprovadas pela ANPD**.

## Passo a passo (2 minutos, feito por quem tem papel de administrador da conta de faturamento/organização)

1. Abra o console do Google Cloud com `bruno.abreu@agencia24por7.com`.
2. Vá em **IAM e administrador → Configurações** (ou **Faturamento → Configurações da conta**) e procure a seção
   **Legal and compliance / Jurídico e conformidade**. Instruções oficiais:
   https://support.google.com/cloud/answer/6329727
3. Em **Data Processing Terms / Cloud Data Processing Addendum**, clique em **Review and Accept**, leia e
   clique em **I Accept**.
4. Na mesma seção, preencha os contatos de privacidade: encarregado (Filipe Jones, contato@agencia24por7.com).
5. Anote aqui a data do aceite: [•].
